# TelyClaw 启动说明（不需要懂编程）

## 最省事的方式：双击

到这个文件夹里，找到 **`start-telyclaw.bat`**，双击它。

```
C:\Users\ss\WorkBuddy\2026-09-10-15-07-45\start-telyclaw.bat
```

会出现一个黑色窗口，几秒后浏览器自动打开 TelyClaw。

**这个黑窗口不能关** —— 它就是服务本身，关掉等于关机。用完直接关窗口即可。

脚本会自动做三件事：找到 Python → 缺依赖就自动装（只有第一次）→ 启动并打开浏览器。
如果服务已经在跑，它会直接帮你打开浏览器，不会重复启动。

> Windows 可能会弹一个"Windows 已保护你的电脑"的蓝色提示，
> 点 **"仍要运行"** 即可（因为这是我们自己写的脚本，没有签名）。

## 第一次使用（只需做一次，用命令行的方式）

1. 打开一个终端窗口
   - Windows：按 `Win + R`，输入 `cmd`，回车

2. 进入项目目录（把路径换成你自己的）

   ```
   cd C:\Users\ss\WorkBuddy\2026-09-10-15-07-45\telyclaw
   ```

3. 安装一次依赖

   ```
   C:\Users\ss\.workbuddy\binaries\python\envs\default\Scripts\pip.exe install -r requirements.txt
   ```

4. 启动

   ```
   C:\Users\ss\.workbuddy\binaries\python\envs\default\Scripts\python.exe app.py
   ```

   看到下面这段就说明启动成功了，浏览器会自动打开：

   ```
   ====================================================
     TelyClaw 已启动
     请打开浏览器访问： http://127.0.0.1:8765
     停止服务：在这个窗口按 Ctrl + C
   ====================================================
   ```

   如果浏览器没自动弹出，手动打开 <http://127.0.0.1:8765> 即可。

5. 停止服务：在那个终端窗口按 `Ctrl + C`

## 每天使用

只需要第 2 步和第 4 步：进目录 → 启动。

---

## 填 AI 密钥（想看 AI 生成的内容就必须填）

1. 打开页面 → 点顶部「设置」
2. 找到 **DeepSeek API Key**，把你的密钥粘进去，点「保存设置」
3. 回到「监控」页重新点一次「立即检测」

没填密钥也能用：热点榜单、热度分、排名都会正常出，只是没有 AI 起的标题、摘要、排名理由、内容角度和帖子文案。

密钥保存在 `telyclaw/data/settings.json` 里，只存在你自己电脑上。

## 演示前建议按顺序点一遍

设置页加 1 个账号 → 刷新页面看它还在不在 → 监控页勾选 5~6 个账号 → 选「过去 24 小时」→ 立即检测
→ 看榜单和排名理由 → 在 Top 精选里换掉一个 → 内容工作台点热点 → 点一个角度 → 选一条帖子 → 改几个字 → 发布

## 出问题怎么办

| 现象 | 怎么办 |
|---|---|
| 双击没反应 / 一闪而过 | 用上面"命令行的方式"启动一次，能看到具体报错 |
| 弹蓝色"Windows 已保护你的电脑" | 点 **"仍要运行"** |
| 提示"端口被占用" | 上一个服务没关。关掉旧的黑窗口再启动 |
| 页面打不开 | 确认黑窗口还开着、地址是 `http://127.0.0.1:8765` |
| 一直提示"连不上 AI 服务" | 检查网络；去设置页确认密钥没填错 |
| 某个窗口查不到帖子 | 换成"过去 24 小时"或"过去 3 天"；1 小时窗口内容本来就少 |
| 想恢复初始状态 | 删掉 `telyclaw/data` 文件夹里的 json 文件，重启服务 |
